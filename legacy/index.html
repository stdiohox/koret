How it runs

Every agent ships with a gate.

Confidence is scored on each run. Anything below the threshold stops and waits for a person instead of guessing. The threshold is yours to set, and every decision is logged.

# the approval gate every Koret agent ships with
async def handle(task, ctx):
    result = await agent.run(task, tools=ctx.tools)

    if result.confidence < ctx.threshold:
        await queue.escalate(
            task,
            reason="below confidence threshold",
            draft=result.output,
        )
        return Outcome.PENDING_REVIEW

    await ctx.audit.write(task, result)
    return await ctx.commit(result)
